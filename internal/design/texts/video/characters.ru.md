# Видео: герои, предметы и фоны

Плоская сцена из прямоугольников и выезжающего текста выглядит мёртвой. Сцена, которая объясняет, — про того, кто что-то делает: герой входит,
машет, показывает на график, удивляется, радуется. Пиши сцену как действия героя, а потом раскладывай вокруг предметы и камеру. Всё рисует
кит кодом (чужой графики и моделей нет): герои с частями и суставами, предметы, фоны и риг, который превращает «машет» в твины на времени сцены.

## Как подключить

В `<head>` доски после `support.js`. Порядок важен; бери только то, что нужно сцене:

```html
<script src="/__lib/motion/gsap.min.js"></script>
<script src="/__lib/motion/MorphSVGPlugin.min.js"></script>   <!-- риг морфит рты: нужен с любым героем -->
<script src="/__lib/motion/DrawSVGPlugin.min.js"></script>    <!-- tk.drawHand, tk.draw -->
<script src="/__lib/motion/tk.js"></script>
<script src="/__lib/motion/art/art.js"></script>
<script src="/__lib/motion/art/heroes.js"></script>
<script src="/__lib/motion/art/props.js"></script>
<script src="/__lib/motion/art/backdrops.js"></script>
<script src="/__lib/motion/rig.js"></script>
```

Рисунок кладут на доску пустым `<svg data-tk-art="имя">`: кит заполняет его до того, как соберётся анимация. Размер и место задай CSS
(`height: 70vh; width: calc(70vh * 400 / 600)`). Цвета следуют теме колоды (`--deck-acc`, `-acc-soft`, `-ink`, `-panel`, `-line`, `-bg`), так что
одна сцена читается в любой теме.

```html
<div class="world">
  <svg class="bg" data-tk-art="bg-office"></svg>            <!-- position:absolute; inset:0; width:100%; height:100% -->
  <svg class="hero" data-tk-art="hero-person"></svg>
  <svg class="chart" data-tk-art="prop-chart"></svg>
</div>
```

## Что есть

| Имя | Что | Части, которые можно двигать (`data-part`) |
| --- | --- | --- |
| `hero-person` | человечек, руки из двух частей | части героя ниже |
| `hero-round` | круглый маскот с листиком, маленькие руки | те же и `tuft` |
| `hero-robot` | угловатый робот, экран-лицо, антенна | те же и `tuft` |
| `prop-laptop` `prop-phone` | ноутбук, телефон с приложением | `screen` |
| `prop-chart` | карточка со столбцами и растущей линией | `bar` (5), `line`, `dot` (5), `arrow` |
| `prop-cloud` `prop-server` | облако со стрелкой, серверная стойка | `arrow`, `led` |
| `prop-gear` `prop-rocket` `prop-bulb` | шестерёнка, ракета с пламенем, лампочка | `gear`, `flame`, `glow` `ray` |
| `prop-doc` `prop-folder` `prop-bubble` `prop-check` | документ, папка с листами, пузырь чата, галочка | `row`, `sheet`, `dot`, `ring` `check` |
| `bg-office` `bg-city` `bg-abstract` | комната, улица, мягкие формы (1600x900, заполняет кадр) | слои `far` `mid` `near` (`data-layer`, `data-depth`) |

Герой 400x600 и стоит на y = 560; у предметов свои размеры (`tk.art.size('prop-chart')`). Части героя: `root` (прыжок), `body` (дыхание), `head`,
`face`, `eyeL` `eyeR`, `pupilL` `pupilR`, `browL` `browR`, `cheekL` `cheekR`, `mouth`, `armL` `armR` (+ `foreL` `foreR`), `legL` `legR`, `shadow`.
`tk.part('.chart', 'bar')` отдаёт элементы части; `tk.pivots('.chart')` заставляет части предмета поворачиваться вокруг своих точек (делай один раз
для любого предмета, части которого масштабируешь или крутишь).

## Действия героя

```js
tk.sceneLength(9);                       // один раз: длина сцены, для того, что длится всю сцену
tkVideo.motion(function () {
  var hero = tk.rig('.hero');            // ставит суставы; бросает ошибку, если это не герой
  hero.alive();                          // дыхание и моргание на всю сцену: каждому герою, всегда

  hero.walk('-48vw', '0vw', 1.7, { at: 0.2 });          // откуда, куда, секунды
  hero.wave({ at: 2.1 });                                // {arm: 'L'} — левой рукой
  hero.talk(1.3, { at: 2.1, text: 'Привет!' });          // рот идёт за буквами; без text — набор слогов
  hero.point('.chart', { at: 3.7, hold: 1.9 });          // рука к цели, глаза следом; опускает через `hold`
  hero.emotion('surprised', { at: 5.5 });                // 'happy' | 'surprised' | 'sad' | 'neutral'; {hold} вернёт нейтральное
  hero.cheer({ at: 6.5 });                               // радость, прыжок, руки вверх
});
```

Каждое действие берёт `at` (секунды от начала сцены) в последнем аргументе. Остальные: `look(куда | цель)` ('left', 'right', 'up', 'down', 'center',
селектор, элемент, `{x, y}` на экране), `blink()`, `nod({times})`, `shrug()`, `jump({height, arms})`, `stand('12vw')` (где начинает). Действия кончаются
в покое, поэтому встают цепочкой. Два действия сразу на одной части (машет и показывает одной рукой, два `talk`) — проверка скажет `motion-overlap`:
бери другую руку или делай одно за другим. Говорить и махать одновременно можно: разные части.

Правила героя:
- **Герой никогда не замирает.** `hero.alive()` — вторичное действие: дыхание и моргание под всем остальным. Без него герой — картинка.
- **Одно главное движение за раз.** Пока герой показывает, глаз идёт к графику, а не к машущей руке и прыгающему маскоту.
- **Поверни героя к тому, о чём он говорит:** это делают `point` и `look`; сначала положи цель на доску, потом вызывай героя (риг меряет, где стоит
  цель, в момент вызова). Всё, что двигает цель через `fromTo` (`tk.enter`, `tk.inertia({from})`), идёт после.
- **Герой откуда-то приходит:** `walk` из-за кадра или `tk.enter` с падением (`tk.physical.drop`); не проявляй его на месте.
- Рот двигается, только пока герой говорит: молчащий герой с живым ртом выглядит как сбой. Сцена без голоса показывает сказанное текстом.

## Предметы, ходы и вес

| Вызов | Что делает | Нужно |
| --- | --- | --- |
| `tk.morph(a, b, {at, dur})` | одна форма в другую | MorphSVGPlugin |
| `tk.drawHand(paths, {at, dur, jitter, fps, seed})` | линия «от руки» с лёгким дрожанием, одинаковым при любой перемотке | DrawSVGPlugin |
| `tk.squash(el, {at, amount, dur})` | вес: сжатие, растяжение, оседание | |
| `tk.inertia(el, {at, dur, from, x, y, scale, overshoot})` | ход, который проскакивает и возвращается | |
| `tk.parallax(layers, {at, dur, amount, depths})` | слои плывут по глубине; `amount` в px, `'6vw'` или единицах рисунка | |
| `tk.camera(world, {...})` `.drift` `.shake` | зум и пан; медленное блуждание; толчок, что затухает (`xPercent`, `yPercent`, `rotation`) | |
| `tk.particles(box, {at, kind, count, x, y, from, seed, dur})` | `'confetti'`, `'sparks'`, `'dust'` из точки или цели | |

```js
tk.pivots('.chart');
var bars = tk.part('.chart', 'bar');
tk.start(bars, { scaleY: 0 });
tk.tl.to(bars, { scaleY: 1, duration: 0.55, stagger: 0.12, ease: 'back.out(1.6)' }, 4.1);   // столбцы растут от пола
tk.drawHand('.chart [data-part=line]', { at: 4.7, dur: 1.3 });                              // линия прорисовывается
tk.particles('.fx', { at: 6.5, kind: 'confetti', x: '25%', y: '30%', angle: -90, spread: 170, seed: 'left' });  // хлопушка из угла
tk.parallax('.bg [data-layer]', { at: 0, dur: 9, amount: 70 });                              // комната плывёт по глубине
tk.camera.drift('.world', { at: 0, dur: 9 });                                                // живая камера
tk.camera.shake('.shake', { at: 6.5, dur: 0.35 });                                           // толчок: на своей обёртке
```

- **Частицы бросаются из зерна:** путь каждой считается заранее, `seed` — имя, одно имя даёт один и тот же залп. Жизнь залпа кончай до конца
  сцены (`at + dur` меньше длины сцены).
- **На один вид движения камеры — одна обёртка:** `tk.camera` зумит (`x`, `y`, `scale`), `drift` и `shake` пишут `xPercent`, `yPercent`, `rotation`;
  `shake` клади на свою обёртку внутри `.world`, чтобы он не встретился с `drift`.
- Вес и затухание: `tk.squash` тому, что приземляется, `tk.inertia` тому, что приходит, `tk.particles` тому, что случилось. Не на каждый элемент:
  глазу нужен отдых.

## Ремесло объяснялки

- **Думай битами:** герой входит (0-2 с), говорит мысль (2-4 с), показывает (4-7 с), реагирует (7-9 с). Один бит — одна фраза сценария.
- **Глубина:** фон с параллаксом, герой впереди, предметы между. Дрейф камеры на 1-2% оживляет неподвижный момент.
- **Единство:** один герой и один фон на видео, одна тема; один и тот же герой выглядит одинаково во всех сценах.
- **9:16:** фон заполняет кадр (`slice`), герой и предметы — в средних 80%: размеры в `vh` и `vmin`, место — смещением `vw` от середины.
- **Свой рисунок:** `tk.art.define('mine', {w, h, body})` с `data-part` и `data-pivot="x y"` даёт предмет, понятный ригу и `tk.part`; крась классами кита
  (`f-acc`, `f-soft`, `s-ink`: заливки и линии темы) и держи стиль: плоско, скруглённо, один тёмный для лиц.
