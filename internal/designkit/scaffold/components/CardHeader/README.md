# CardHeader

The top row of a Card: its title, set apart from the content.

## When to use

- Inside a Card, first.

## When not to use

- Outside a Card: a heading of the page.

## Props

| Prop | Type | Default | What |
| --- | --- | --- | --- |
| `title` | string | — | the card's title, a noun |

## Example

```html
<x-import component-from-global-scope="__NS__.CardHeader" title="Spring concert"></x-import>
```
