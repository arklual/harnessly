# CardBody

The content of a Card under its header, with the card's padding.

## When to use

- Inside a Card, after CardHeader.

## When not to use

- Outside a Card: plain content of the page.

## Props

| Prop | Type | Default | What |
| --- | --- | --- | --- |
| `children` | node | — | text and components |

## Example

```html
<x-import component-from-global-scope="__NS__.CardBody">May 14, 8 pm.</x-import>
```
