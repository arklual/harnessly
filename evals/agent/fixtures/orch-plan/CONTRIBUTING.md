# Правила репозитория

- `generated/` руками не правится: он собирается из `api.yaml` командой `python3 gen.py`, ручная правка затрётся при следующей сборке.
- `vendor/` — чужой код (библиотека партнёра), его не меняем никогда; если наш интерфейс меняется, совместимость держим прослойкой в `app/compat.py`.
- Перед коммитом: `python3 -m unittest discover -s tests -t .`
