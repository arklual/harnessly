# Уведомления: спросить человека в умном уведомлении

Умное уведомление — чёрная плашка вверху экрана. В ней то, что ждёт человека: код, вопрос агента, готовый чат. Ваше
приложение и ваш агент могут показать там свой элемент и получить ответ, не уводя человека от того, чем он занят.
Одно описание работает тремя путями:

| Кто спрашивает | Как |
|---|---|
| Окно приложения | `hl.notice.ask(spec)`, `hl.notice.show(spec)` (нужно право `notices` в `app.json`) |
| Агент из терминала | `harnessly notice ask …`, `harnessly notice show …` |
| Агент через MCP | тулы `notice_ask`, `notice_show`, `notice_update`, `notice_close` |

Над каждой плашкой — метка источника, её нельзя подделать: «Приложение · <имя из манифеста>» или «Агент · <название
чата>». Вы присылаете только текст под ней.

## Что можно показать

| Вид | Внутри | Ответ | Когда брать |
|---|---|---|---|
| `status` | иконка и строка-две | нет; уходит сам через ~8 с | что-то закончилось или началось |
| `progress` | полоса, двигается через `update` | нет; висит до `close` или срока | долгая работа, которую человек ждёт |
| `choice` | вопрос и 2–6 вариантов (`own: true` — строка для своего ответа) | `{choice, option}` или `{text}` | развилка, которую решает человек |
| `confirm` | что будет, «да» и «нет» (`danger: true` — необратимое) | `true` / `false` | перед необратимым шагом |
| `field` | одна строка текста (`placeholder`) | текст | имя, заголовок, короткий комментарий |
| `code` | 4–8 ячеек для цифр (`digits`) — только приложениям | цифры | код подтверждения (письмо о подписке, привязка устройства) — не код входа |
| `custom` (только приложениям) | ваша разметка и кнопки, до 420×320 | `data-answer` нажатой кнопки | когда готовых не хватает |

```js
// В окне приложения (в манифесте в permissions есть "notices")
const r = await hl.notice.ask({
  kind: 'choice',
  title: 'Куда выкатить сборку 482?',
  options: ['На стенд', 'В тест', 'Никуда'],
  own: true,
});
if (r.status === 'answered') deploy(r.value.option ?? r.value.text);

const { id } = await hl.notice.show({ kind: 'progress', title: 'Собираю сборку 482', progress: 0 });
await hl.notice.update(id, { progress: 0.6, text: 'Тесты · 120 из 200' });
await hl.notice.close(id);
```

```sh
# Из агента
harnessly notice ask --kind confirm --title "Удалить 3 старые таблицы?" --text "orders_tmp, orders_bak" --danger --yes "Удалить"
# {"status":"answered","value":true}   (код выхода 4, если ответа нет)
```

`ask` возвращает `{status, value}`:

- `answered` — в `value` ответ (см. таблицу);
- `dismissed` — человек отказался или закрыл;
- `timeout` — никто не ответил вовремя (`timeoutSec`, по умолчанию 10 минут, максимум сутки);
- `muted` — человек выключил уведомления от вас.

«Скрыть» — не ответ: вопрос ждёт маленькой «каплей» в правой колонке чата, и человек к нему вернётся.

## Стиль: токены и набор классов

Готовые виды рисует harnessly в стиле плашки — с теми же пружинами, стопкой и «каплей». Вид `custom` рисуется прямо в
плашке и только описывает: разметка, текст, кнопки. Скриптов, обработчиков, полей, форм, фреймов и ссылок в нём нет — вид
не может выполнить код, попросить что-то ввести или увести человека на другую страницу. Вид, который это приносит,
отклоняется (`bad-notice`), а страница рисует только разрешённое.

Что можно в виде:

- теги: `div`, `span`, `p`, `b`, `strong`, `i`, `em`, `small`, `br`, `hr`, `ul`, `ol`, `li`, `h3`, `h4`, `button`,
  `img` (`src` только `data:image/png|jpeg|webp|gif;base64,…`);
- атрибуты: `class` (только классы набора `ink-*`), `data-answer`, `data-on`, `data-tone`, `alt`, `aria-label`, `title`.

Кнопка с `data-answer` отвечает: значение как JSON, а если это не JSON — как текст. Вид получает токены:

| Токен | Что это |
|---|---|
| `--ink-bg`, `--ink-fg` | чёрный и белый плашки |
| `--ink-fg2`, `--ink-fg3` | второстепенный и тихий текст |
| `--ink-fill`, `--ink-fill2` | поверхность на плашке и поплотнее |
| `--ink-line` | тонкая линия |
| `--ink-danger` | необратимое |
| `--ink-radius`, `--ink-radius-lg`, `--ink-gap` | скругления и отступы |

и классы на них: `.ink-grid`, `.ink-row`, `.ink-end`, `.ink-tile` (`data-on` — отмеченная), `.ink-btn`
(`data-tone="soft"` или `"danger"`), `.ink-panel`, `.ink-text`, `.ink-muted`. Ваши `<style>`, атрибуты `style` и другие
классы выбрасываются: свой вид выглядит как плашка — или не показывается.

```js
const r = await hl.notice.ask({
  kind: 'custom',
  title: 'Какую обложку взять?',
  view: `
    <div class="ink-grid">
      <button class="ink-tile" data-answer='{"cover":"dark"}'>Тёмная</button>
      <button class="ink-tile" data-answer='{"cover":"light"}'>Светлая</button>
    </div>
    <p class="ink-muted">Обложка встанет на все письма рассылки.</p>`,
});
// r.value → {cover: 'dark'}
```

Плашка растёт по высоте вида, максимум 320 px. Агент свой вид прислать не может: у него готовые виды.

## Никогда: пароли, ключи, вход

Слот не спрашивает секреты, и заставить его нельзя:

- поля-пароля нет ни в одном виде и не будет;
- `field` или `code`, в тексте которых просят пароль, ключ, токен или вход, отклоняются (`no-secrets`);
- в `custom` полей нет вовсе: вид с полем, формой, скриптом или ссылкой отклоняется, и страница их не рисует;
- текст, похожий на ключ (`sk-…`, `ghp_…`, JWT, приватный ключ, длинная случайная строка), не уходит: плашка говорит
  положить его в сейф, а машина отклонит его ещё раз (`looks-like-key`);
- агент не получает одноразовый код через слот: `harnessly secret run --code` кладёт его прямо в команду, которой он нужен.

Для секретов — сейф: агенту `harnessly secret ask NAME --why …`, приложению `hl.secrets.put` и право `secrets`. Для
входа на сайт — вход из сейфа в браузере. См. [Вход](10-auth.md).

## Лимиты и что может человек

Чтобы слот оставался у человека, а не у самого громкого приложения:

- приложению нужно право `notices` в манифесте; при установке человек видит «Спрашивать вас в умном уведомлении»;
- от одного источника в чате показывается одно ожидание, на машине — не больше трёх; остальные ждут очереди (всего
  открытых не больше двенадцати, дальше `busy`);
- не чаще 5 новых уведомлений в минуту от источника (`too-often`); тот же вопрос, пока он открыт, склеивается с ним;
- `status` и `progress` без звука и без «капли»; вопросы звучат как вопрос агента;
- в меню плашки есть «Не показывать от …»: источник выключен, пока человек его не включит, а его открытые уведомления
  кончаются как `muted`.

Спрашивайте решение, без которого работа не пойдёт дальше. Прогресс, которого человек не ждёт, рутинные новости и всё,
что помещается в чат, — в чат.
