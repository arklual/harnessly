# Работа агента в harnessly

Вы работаете во вкладке harnessly: человек общается с вами в чате, на настоящей машине, в папке проекта. Правая
панель рядом с разговором показывает то, что вы делаете. В других вкладках — терминалы и другие агенты. Этот раздел
написан для вас, агента; человек тоже его читает, чтобы знать, что знаете вы.

## Что у вас есть

- **Промпт рабочего пространства**: с кем говорит человек, id пространства, команда `harnessly`, как отображаются
  ваши ответы. Приходит с каждым чатом.
- **Команда `harnessly`** в PATH. Она сама находит рантайм, входить никуда не надо.
- **Скиллы**: документы и доски, рабочее пространство, написание приложений; те, что человек включил в настройках.
- **Подключения человека**: его трекер, вики и хостинг кода через `harnessly issues`, `harnessly pages`, и
  подключённые им MCP-серверы, уже с входом.
- **Сейф**: секреты по имени, никогда по значению (`harnessly secret`).

## Команда вкратце

```bash
harnessly docs search <слова>        # эта документация и документация команды: прочитайте, прежде чем гадать
harnessly open <ссылка|файл|порт>    # показать человеку в правой панели
harnessly deliver <файл>             # отдать файл, который человек просил: карточка в чате
harnessly tab create -t codex-cli --prompt "<вся задача>"   # запустить другого агента
harnessly peers                      # чаты других агентов, которым можно написать
harnessly secret run --env VAR=NAME -- cmd   # выполнить команду с секретом из сейфа
harnessly issues --mine --open       # задачи человека в его трекере
harnessly --help                     # всё, с примерами
```

## Правила дома

1. **Показывайте, а не описывайте.** Опубликованный документ, нарисованную доску, запущенный dev-сервер откройте в
   панели (`harnessly open`) или назовите адрес в ответе — он откроется один раз.
2. **Отдавайте только то, что просили.** `harnessly deliver` — для файла, который человек хочет получить, а не для
   каждого тронутого файла.
3. **Секреты — через сейф.** Никогда не просите токен в чате, не печатайте его и не пишите в файл.
   `harnessly secret ask NAME --why "…"` даст человеку карточку, куда его вписать.
4. **Другого агента — способом платформы.** `harnessly tab create --prompt` даёт ему хуки и промпт; `claude`,
   набранный в оболочке, — нет.
5. **Сначала спросите документацию.** Как работает harnessly и как всё устроено у этой команды, записано:
   `harnessly docs search`. Если выяснили то, чего в документации не было, предложите [дописать](docs.md).

## Как отображаются ваши ответы

Блок кода с пометкой `mermaid` становится схемой; с пометкой `html` — страницей в песочнице с переключателем на
исходник. Ссылка на документ или доску отдельной строкой — карточка. Ключ задачи, MR или сайт в тексте — чип,
который человек открывает в панели.
