# Кешбэки

Банк даёт выбрать до трёх категорий кешбэка на месяц. Человек выбирает их в окне приложения; выбор лежит в данных
этого чата под ключом `picks:<ГГГГ-ММ>` (например `picks:2026-11`) как `{"month":"2026-11","picks":["gas","cafe"]}`.

- Выбор читай через `app_data_get` (ключ `picks:<месяц>`), не спрашивай то, что уже выбрано.
- Предлагаешь другой набор — запиши его через `app_data_set` только после ответа человека на `app_ask`
  («Заменить выбор на …?» с вариантами «Заменить» и «Оставить»).
- Чтобы показать окно, вызови `app_open`.
- Категории и проценты в приложении демонстрационные: не выдавай их за условия настоящего банка.

## В сайте (Sinopia)

Приложение включено в сайтах: в доску можно добавить карточку кешбэка (`app_sinopia_boards_add`, шаблон `cashback-card`).
Поля карточки (`title`, `percent`, `limit`, `note`, `link`) читай через `app_sinopia_fields` и пиши через
`app_sinopia_set_fields`: значение вне схемы приложение откажет, доска останется как была. Остальные элементы карточки
править вручную нельзя (`lockUnbound`).
