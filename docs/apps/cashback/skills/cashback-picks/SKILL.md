# Подбор категорий кешбэка

1. Прочитай текущий выбор: `app_data_get` с ключом `picks:<ГГГГ-ММ>`.
2. Если выбора нет, покажи окно (`app_open`) и скажи, что выбирать нужно там.
3. Сравни категории по проценту и лимиту в месяц; назови самую выгодную по тратам, о которых человек рассказал.
4. Менять выбор можно только через `app_ask` и `app_data_set`; окно подхватит запись само.
