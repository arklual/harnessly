# Мои задачи из Трекера

Виджет сайдбара (`side`), который показывает ваши открытые задачи из Яндекс Трекера. Пример `hl.connections` из
`@harnessly/app-sdk` ([docs/apps.md](../../apps.md), «The person's connections»): приложение не хранит ключей, а читает
через подключение «Яндекс Трекер» из «Настройки → Подключения», то есть то же, что агенты видят через `harnessly-hub`.

- **Манифест** просит `connections.read` и называет одно подключение, `yandex-tracker`, с доступом `read`.
- **Согласие.** Пока вы не разрешили приложению это подключение (кнопка «Разрешить чтение» открывает карточку хоста
  или «О приложении → Настройка»), виджет пишет, что согласия нет. Согласие можно забрать там же.
- **Состояния.** Нет подключения, ждёт входа, выключено, не отвечает, нет согласия, пусто, список: у каждого свой текст.
- **Только чтение.** Поиск `POST /issues/_search` каталог числит чтением; создать или изменить задачу виджет не может,
  и манифест этого не просит.

Поставить: `harnessly app install docs/apps/tracker-side`.
