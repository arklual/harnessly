# Стоп-кран

Пример приложения на `hooks.agent` и `background` (HRN-852). Хук слышит каждый вызов инструмента агента в чате, где
приложение включено, и останавливает команды `rm -rf` и `git push --force` до запуска. Агент получает причину
словами, в ленте видно «Остановлено приложением Стоп-кран» и кнопку «Выключить хук».

Хук только останавливает или пропускает: менять аргументы вызова приложение не может. Если окно не ответило за 5 с,
вызов проходит, а в журнале приложения остаётся строка. С `background` окно работает скрытым, пока чат открыт, так что
панель держать открытой не нужно. В окне — что и когда остановлено.

Это пример, а не защита: правила разбирают команду на слова и ловят флаги в любом порядке, под `sudo`, `env` и
`bash -c`, но обойти их можно (переменная, скрипт в файле, другой инструмент). Стоп-кран без `hooks.strict` при
молчании окна пропускает вызов. Для проверки, от которой зависит безопасность, нужен `hooks.strict` и правило
«что не понял — останавливаю».

Поставить для проверки: `harnessly app install --dev docs/apps/guard` и включить в чате.
