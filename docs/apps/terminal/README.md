# Терминал

Пример приложения на `terminal.pty` (HRN-852): тот же терминал, что во вкладке правой панели, собранный на SDK.
Окно рисует [xterm](https://xtermjs.org) (лежит в `ui/vendor`, лицензия MIT), `hl.terminal.open` даёт оболочку на своём
pty, а нажатия и вывод идут через мост хоста.

Право одно — `terminal.pty`, критического класса: в терминале можно выполнить что угодно с правами агента. Оболочка
работает в песочнице агента: в папке чата, без ключей человека (`~/.ssh`, `~/.config`, сейф закрыты) и без секретов
окружения рантайма. Открытие и конец терминала записаны в журнал приложения, нажатия — нет. Когда приложение
пользуется агент, хост спрашивает человека перед открытием и перед каждым вводом, показывая текст целиком.

«Замер» печатает 50 букв по одной и считает время от нажатия до эха: медиану и 95-й процентиль.

Поставить для проверки: `harnessly app install --dev docs/apps/terminal`, включить в чате и открыть в панели.
