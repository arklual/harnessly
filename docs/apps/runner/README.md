# Запуск

Пример приложения на `terminal.run` и `process`: окно запускает тесты папки чата и показывает их вывод,
поднимает dev-сервер и открывает его во встроенном браузере правой панели (`hl.preview.open`). Терминал не нужен.

Права:

- `terminal.run` — команда тестов (по умолчанию `npm test`); любая команда, поэтому право высокого класса. Узкий
  вариант — `terminal.run:npm test*`: тогда приложение запускает только то, что подходит под маску, без оболочки;
- `process` — dev-сервер (по умолчанию `npm run dev`) и его вывод, открыть порт в панели;
- `storage` — помнить команды и порт для этого чата;
- `tools.page` — инструмент `run_tests` для агента: когда его вызывает агент, хост спрашивает человека.

Команды идут в песочнице агента: в папке чата, без ключей человека (`~/.ssh`, `~/.config`, сейф закрыты), с лимитом
времени, процессорного времени и вывода. Каждый запуск записан в журнал приложения.

Поставить для проверки: `harnessly app install --dev docs/apps/runner`, включить в чате и открыть в панели.
