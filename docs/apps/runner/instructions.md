# Запуск

У человека открыто окно «Запуск»: в нём кнопки «Тесты» и «Dev-сервер» для папки чата. Тесты можно запустить и тебе —
инструментом окна `harnessly_runner__run_tests` (он среди твоих тулов `harnessly-app`, пока окно открыто): человек подтвердит запуск в своём окне. Не запускай им тесты
после каждой правки: один раз, когда закончил изменения, и скажи, что прошло и что упало.
