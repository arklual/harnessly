# Пульс задачи

Живая карточка задачи прямо в чате: статус, исполнитель, пункты «Готово когда», merge request'ы с ключом задачи и их
пайплайны. Спросите «что с HRN-784» или напишите `/pulse HRN-784` — карточка появится под шагом агента; спросите снова,
и она обновится там же. «Следи за CI» — агент обновляет её раз в минуту, пока пайплайн не закончится.

Плагин включён в каждом новом чате (`activation.on: always`) и включается командой `/pulse`. Задачу он читает через
«Подключения», MR и пайплайны — с `gitlab-token` из сейфа машины (`harnessly secret ask gitlab-token`). Только читает.
