# Исправление замечаний

1. Найди тексты слайдов: `app_sinopia_query` с селектором `h1, h2, h3, p, li`; в ответе у каждого узла есть `id`, `text` и `fp`.
2. Для длинного блока (больше 40 слов) напиши короткий вариант: одна мысль, без вводных слов.
3. Применяй правки одним `app_sinopia_patch`: `{"op":"setText","node":"<id>","value":"…","fp":"<fp>"}`. Если узел успел
   измениться, патч откажет целиком: прочитай слайд заново.
4. Мелкий шрифт правится `setStyle` с `{"font-size":"24px"}`.
5. Если чат уже правит слайд, патч откажет с `policy_blocked`: подожди или скажи человеку.
