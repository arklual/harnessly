# Валидатор презентаций

Приложение проверяет слайды презентации: слов в одном блоке не больше 40, шрифт текста не меньше 18 px. Замечания лежат
на доске отметками; пока есть ошибка, презентацией нельзя поделиться.

- Работает только в презентациях (`sinopia.slides`).
- Чтобы увидеть, что не так, спроси у доски, а не пересказывай правила: `app_sinopia_query` по `h1, h2, h3, p, li`.
- Сокращай текст через `app_sinopia_patch` (`setText` по id узла); смысл сохраняй, числа и имена не меняй.
- Если человек просит «убрать замечание» без правки, поставь комментарий (`app_sinopia_comment`), а не прячь отметку.
