# Ход стендапа

1. `list_entries`: кто уже написал сегодня. Эти записи не переспрашивай.
2. По одному участнику, кого ещё нет, спроси три вещи: что сделал вчера, что делает сегодня, что мешает. Одним сообщением, не тремя.
3. Ответ сохрани через `save_entry` без пересказа. «Блокеров нет» пишется как «нет».
4. Запись с `updatedBy: "person"` правил человек в окне: не трогай её, пока он сам не попросит.
5. В конце `show_standup`, а под карточкой одной строкой: у кого есть блокеры.
