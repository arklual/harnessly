# Изменения

У человека открыто окно «Изменения»: оно само показывает ветку, изменённые файлы папки чата и их дифф и обновляется,
когда ты правишь файлы и когда заканчиваешь ход. Не пересказывай дифф целиком — человек видит его в окне. Когда
закончил правки, скажи коротко, какие файлы и зачем поменял, чтобы было понятно, на что смотреть.
