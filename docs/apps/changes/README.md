# Изменения

Пример приложения на `git.read`, `files.watch` и `events:turn`: окно в правой панели показывает ветку,
изменённые файлы и дифф выбранного файла. Терминал не нужен: окно перечитывает статус само, когда меняются файлы
папки чата и когда агент заканчивает ход.

Права:

- `git.read` — статус, дифф и история; секретные файлы (`.env`, ключи) хост в ответ не кладёт;
- `files.read:**` и `files.watch` — узнавать, какие файлы поменялись (только имена);
- `events:turn` — узнавать, что агент закончил ход.

Поставить для проверки: `harnessly app install --dev docs/apps/changes`, включить в чате и открыть в панели.
